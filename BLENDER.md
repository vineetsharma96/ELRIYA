# Blender MCP Rules

Blender MCP is Elyria's primary asset creation pipeline.

Create original:
- Protagonist
- NPCs
- Companion
- Vehicles
- Buildings
- Interior modules
- Trees
- Vegetation
- Props
- Landmarks

Do NOT create the whole city inside Blender.

Create reusable modular assets and assemble the city at runtime.

## Every Important Asset

1. Model
2. Clean topology
3. Correct scale
4. Materials
5. UVs when required
6. Correct origin/pivot
7. Collision mesh if needed
8. LOD variants when useful
9. Optimize
10. Export GLB/glTF
11. Test in runtime

Keep the cute rounded Elyria art direction consistent.

Prefer reusable modular kits over hundreds of unique assets.
